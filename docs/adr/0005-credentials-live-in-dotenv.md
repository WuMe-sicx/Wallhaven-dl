# 凭据放 .env，不新建配置文件

需要保存的是图床地址、token、储存 id，以及 wallhaven 的 API key。没有新建 `config.json` 之类的文件，而是复用 `.env`。

理由是 `.env` **已经在 `.gitignore` 第 79 行**。新建一个配置文件意味着同时得记得往 `.gitignore` 加一行——而这个仓库正是因为凭据入库出过事（`e4f2a78` "Removed Private API Key"）。少一个「必须记得忽略」的文件，就少一条泄漏路径。

顺带的好处：`.env` 里的键名与脚本读取的环境变量名完全相同，不需要维护「配置字段 ↔ 环境变量」的映射，也不引入第二套命名。

## Consequences

- 解析只认最朴素的 `KEY=value`：跳过空行与 `#` 注释，剥掉值两端引号，**不做 `$VAR` 展开**。装成支持 shell 语法会让人以为整套都能用。
- 已 `export` 的真环境变量优先于 `.env`，便于临时覆盖。
- `.env` 被忽略后没人知道该填什么，因此附一份 `.env.example` 进版本库——它是唯一的发现路径，**新增配置项时必须同步更新它**。
