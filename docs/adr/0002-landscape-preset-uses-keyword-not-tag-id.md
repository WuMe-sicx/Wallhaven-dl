# 「风景」预设用关键词 landscape，而非精确标签 id:711

wallhaven 有一个 id 为 711 的 `landscape` 标签（官方 alias 里就含「山水风景」），用 `q=id:711` 检索比关键词精确得多——40480 张确切打了该标签，而 `q=landscape` 有 50068 张，多出的部分靠标题等文本匹配。尽管如此，本预设仍使用关键词。

原因是 `id:` 语法不能与其他检索词共存：实测 `q=id:711 +sunset` 返回 **0 张**，而 `q=landscape sunset` 返回 5169 张。选了精确标签就等于独占整条 q 轴，用户无法在「风景」之上再叠加自己的关键词，与 ADR-0001 确立的可叠加模型直接冲突。

**不要把这里"优化"成 `id:711`**——精度的提升会以牺牲叠加能力为代价，而叠加是这个模型存在的理由。若将来 wallhaven 支持 `id:` 与其他词组合，此决定可以重新考虑。
